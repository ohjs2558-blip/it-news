대기 중

검색어를 입력하고 [검색하기]를 누르면 실시간 분석 브리핑이 생성됩니다.

최신 기사 5건을 기반으로 3대 관점(핵심 요약, 최신 동향, 개발자 시사점) 카드 뷰로 깔끔하게 정리해 드립니다.

⚡

IT News 시스템 아키텍처 & Render 클라우드 동작 원리 Render Cloud Native

사용자 브라우저 ➔ Render 전역 CDN & Reverse Proxy ➔ Render Python 컨테이너 (server.py) ➔ Google News RSS & Gemini 3.1 Flash-Lite AI 연동 구조

🗺️ 시스템 구성 컴포넌트 맵 (Architecture Components) End-to-End Pipeline
1. Client (Browser) news.html

사용자 검색 키워드를 감지하여 fetch('/api/chat') 비동기 요청 전송 및 2단 분할 렌더링을 담당합니다.

기술: Vanilla JS, Tailwind CSS
2. Render Cloud Web Service Render.com

Render Managed Web Service 환경에서 server.py 컨테이너가 24시간 실행되며, 내장 TLS 종단과 자동 무중단 배포(Auto-Deploy), 헬스체크(/health)를 수행합니다.

인프라: Render Linux Container (Python 3.14) Auto-Deploy: On
3. Google News RSS External API

검색어와 관련된 최신 기사 5건(제목, 언론사, 링크, 본문 요약)을 실시간 XML로 공급받아 정제합니다.

기술: urllib, ElementTree XML
4. Gemini 3.1 Flash-Lite Generative AI

수집된 기사 원문을 초고속 인공지능 모델이 분석하여 1) 핵심요약, 2) 기술동향, 3) 개발자 시사점 3대 관점으로 브리핑을 완성합니다.

기술: Google GenAI Client / REST
실시간 데이터 스트림 파이프라인 (Data Pipeline) (원하는 노드를 클릭하면 해당 구간의 내부 메커니즘을 상세히 조회합니다) ACTIVE STREAM

1단계 · 비동기 HTTPS 요청 🙋‍♂️

클라이언트 요청 전송

브라우저가 Render 호스팅 도메인(it-news-gemini.onrender.com)의 POST /api/chat 엔드포인트로 JSON 검색어를 안전하게 비동기 전송합니다.

프로토콜: HTTPS / TLS (Render Edge)
2단계 · Render 컨테이너 & 수집 ☁️

Render Server & RSS

Render Web Service에서 24시간 상시 가동 중인 Python 컨테이너가 요청을 수신하고, Google News RSS 가판대에서 최신 기사들을 실시간 수집 및 XML 파싱합니다.

실행 환경: Render Managed Container
3단계 · 백엔드 ➔ Gemini 연동 🧠

Gemini 3.1 Flash-Lite 추론

Render 환경변수(GEMINI_API_KEY)를 주입받은 백엔드 서버가 Google GenAI API와 통신하여 3대 관점의 분석 브리핑을 실시간 생성합니다.

보안 설정: Render Environment Secrets
4단계 · 응답 ➔ 브라우저 렌더 🎁

클라이언트 2단 동시 표출

Render 웹 서비스를 통해 전달된 JSON 응답을 받아 화면 왼쪽에는 뉴스 원문 카드를, 오른쪽에는 AI 요약을 즉시 동적 렌더링(DOM render)합니다.

최종 처리: DOM 동적 렌더링 완료
