IT News 시스템 아키텍처 & 실시간 동작 원리 실시간 동기화

브라우저(Client) ➔ 백엔드(server.py) ➔ Google News RSS ➔ Google Gemini AI 2.5 Flash 연동 구조

🗺️ 시스템 구성 컴포넌트 맵 (Architecture Components) End-to-End Pipeline
1. Client (Browser) news.html

사용자 검색 키워드를 감지하여 fetch('/api/chat') 비동기 요청 전송 및 2단 분할 렌더링을 담당합니다.

기술: Vanilla JS, Tailwind CSS
2. Render Cloud Backend Render.com

2단계부터 Render 클라우드 인프라에서 server.py가 동작하며, RSS 수집 및 Gemini AI 추론을 전담 처리합니다.

호스팅: Render Web Service port: $PORT
3. Google News RSS External API

검색어와 관련된 최신 기사 5건(제목, 언론사, 링크, 본문 요약)을 실시간 XML로 공급받아 정제합니다.

기술: urllib, ElementTree XML
4. Gemini 2.5 Flash Generative AI

수집된 5개 기사 원문을 분석하여 1) 핵심요약, 2) 기술동향, 3) 개발자 시사점 3대 관점으로 브리핑을 완성합니다.

기술: Google GenAI Client / REST
실시간 데이터 스트림 파이프라인 (Data Pipeline) (원하는 노드를 클릭하면 해당 구간의 내부 메커니즘을 상세히 조회합니다) ACTIVE STREAM

1단계 · 비동기 HTTP 요청 🙋‍♂️

검색 키워드 전송

브라우저가 POST /api/chat 엔드포인트로 JSON 페이로드 {"query": "..."}를 비동기로 전달하고 UI를 로딩 모드로 전환합니다.

프로토콜: HTTP POST JSON
2단계 · Render 클라우드 수집 ☁️

Render 백엔드 & RSS

Render Web Service 환경의 백엔드가 Google News RSS에 접근하여 최신 기사 5건을 실시간 수집 및 XML 파싱합니다.

실행 환경: Render Server ($PORT)
3단계 · Render ➔ Gemini 연동 🧠

Gemini 2.5 Flash 추론

Render 서버가 환경변수(GEMINI_API_KEY)로 Gemini API와 보안 통신하여 3대 관점의 브리핑을 생성합니다.

API 키 보안: Render Secret Env
4단계 · Render 응답 ➔ UI 렌더 🎁

클라이언트 2단 동시 표출

Render 서버에서 온 JSON 응답을 받아 화면 왼쪽에는 뉴스 원문 카드 5개를, 오른쪽에는 AI 요약을 즉시 렌더링(DOM render)합니다.

최종 처리: DOM 동적 렌더링 완료
